# Промо-ролик Qaita (вертикальный, 30 с)

**Файл:** [`out/qaita-promo.mp4`](out/qaita-promo.mp4) — 1080×1920, 30 к/с, H.264 + AAC, 30 с.
Для Reels / Shorts / TikTok и как заставка на питче. Весь текст — в безопасной зоне (y 300–1480): не заходит под ник сверху и подпись с кнопками снизу.

## Сценарий (склейки на долях, 120 BPM)
| Время | Сцена | Что на экране |
|---|---|---|
| 0–3 с | Хук | удар на каждую долю: «КАЖДЫЙ / ГОД / 40 000 / ИНСУЛЬТОВ / В КАЗАХСТАНЕ», счётчик, тряска, зум в цифру |
| 3–6 с | Боль | пять человечков, четыре гаснут: «Реабилитацию получает каждый пятый» → «Остальные — дома. Одни.» |
| 6–9 с | Боль врача | кольцо-таймер, сердцебиение: «15 минут у врача. Он не видит, что дома.» |
| 9–11 с | Поворот | «А если реабилитолог — дома?», райзер, белая вспышка, на дропе — логотип шаңырақ-Q, «қайта — снова» |
| 11–15 с | Решение | «Ссылка. Вебкамера. Всё.», ноутбук с настоящим экраном Qaita, кольцо «покажи ладонь» |
| 15–19 с | Режим «ошибка» | настоящий кадр «Плечо поднято к уху. Опустите!» → штамп «Так правильно! +50» |
| 19–23 с | «Шаңырақ» | юрта строится по долям (7 этапов), растёт сад апорта, падают яблоки: «Каждый день — часть дома» |
| 23–26 с | Врач | кабинет врача по QR, флажки, «В медкарту — одним нажатием», «Қазақша · Русский» |
| 26–30 с | Финал | чистый кадр: логотип, «Qaita возвращает руку в жизнь», marvindpp.github.io/qaita |

Стоковые видео и чужая музыка **не используются**.

## Пересобрать
```bash
cd promo
npm i
npm run music            # public/music.wav из кода
npx remotion render src/index.jsx Promo out/qaita-promo.mp4 --codec h264 --crf 18 \
  --browser-executable=/path/to/chrome-headless-shell   # если Remotion не скачивает свой
node scripts/stills.mjs 40,300,900   # ключевые кадры в out/frames для проверки
```
Сетка сцен и музыки — одна: [`src/timing.js`](src/timing.js). Сцены — [`src/Promo.jsx`](src/Promo.jsx), общие детали (палитра, «войлочное» зерно, стёжка, орнамент) — [`src/kit.jsx`](src/kit.jsx).

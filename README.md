# Qaita — реабилитолог в каждой вебкамере

**Qaita** (каз. «қайта» — «снова») — домашний тренажёр для упражнений на руку после инсульта. Человек открывает ссылку и садится на стул перед ноутбуком. Камера считает повторы, **замечает компенсации** (наклон корпуса, плечо к уху, согнутый локоть, не та рука) и голосом подсказывает, что исправить, как реабилитолог рядом. Упражнения поданы как игра «Сад Qaita»: звёзды, цветы, серия дней. Прогресс сохраняется и собирается в отчёт «показать врачу».

**Для кого:** человек 50–75 лет после инсульта, вернулся домой, одна рука ослаблена. Реабилитолог приходит раз в неделю или не приходит вовсе.

**Проще всего:** откройте https://marvindpp.github.io/qaita/ в Chrome, Edge или Safari и разрешите камеру. Это **единственный клик** в приложении: всё остальное делается жестами перед камерой.

### Если не грузится

Сам сайт — статичные файлы на GitHub Pages. Распознавание (MediaPipe от Google, лицензия Apache 2.0) браузер скачивает при первом запуске, **~26 МБ**, и **с того же сайта**, а не с чужих CDN: школьный или больничный фильтр, который режет jsdelivr и googleapis, запуску не мешает. Если своих файлов нет (например, в `npm run dev` без `npm ci`), сайт сам берёт их с CDN (`src/engine/models.js`).

| Что | С нашего сайта | Запасной адрес | Размер |
|---|---|---|---|
| движок распознавания (WebAssembly) | `./mediapipe/wasm/` (копирует `scripts/copy-wasm.mjs` из `node_modules` при `npm run dev` / `build`) | `cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1/wasm/` | ~12 МБ |
| модель позы | `./models/pose_landmarker_lite.task` | `storage.googleapis.com/mediapipe-models/…/pose_landmarker_lite.task` | 5,8 МБ |
| модель кисти | `./models/hand_landmarker.task` | `storage.googleapis.com/mediapipe-models/…/hand_landmarker.task` | 7,8 МБ |
| шрифт Manrope (необязательно) | — | `fonts.googleapis.com`, `fonts.gstatic.com` | — |

- **«Готовлю распознавание…»** с советами — идёт загрузка (на телефоне до минуты). Если видеокарта телефона зависла, через 12 с распознавание само переходит на процессор.
- **«Не загрузилось распознавание. Проверьте интернет и обновите страницу»** — нет интернета или оборвалась загрузка. Обновите страницу; помогает другая сеть (раздача с телефона).
- **«Загрузка идёт слишком долго»** — за минуту с открытой камерой модели не скачались (медленная сеть). Подождите: если догрузятся, экран сам вернётся к «Покажите ладонь». Или обновите страницу — второй раз файлы берутся из кэша браузера.
- **«Нет доступа к камере»** — значок камеры в адресной строке → «Разрешить» → обновить страницу. Камера работает только по `https://` или на `localhost`.
- Проверить интерфейс **без камеры и без моделей**: `https://marvindpp.github.io/qaita/?mock=1` — виртуальный пациент проходит весь сценарий сам (с CDN ничего не качается).

### Как сесть (экран «Подготовка» проверяет это сам)

1. 🪑 Сядьте на стул, лучше без подлокотников.
2. 💻 Камера на уровне груди, примерно в 1 метре.
3. 💡 Свет спереди, не сидите спиной к окну.
4. 🙋 В кадре голова, плечи, обе руки и место над головой.
5. 👕 Одежда с рукавами, не балахон.
6. ✋ Больно — стоп: две ладони к камере = пауза.

Пока кадр плохой (темно, далеко, близко, не видно локтей), калибровка не начинается, а приложение говорит, что поправить.

## Сценарий

Приветствие → Подготовка (живая проверка кадра) → (если вчера было задание — «Получилось?» 👍) → Выбор руки (или 🪞 зеркальный режим) → **«Ради чего вы занимаетесь?»** (цель выбирается дотягиванием ладони до пузыря) → Калибровка «Твоя норма» → 3 упражнения под выбранную цель, из 5 в каталоге (перед каждым — анимированный человечек-демо, в игре — «тень-тренер»: полупрозрачная рука из вашего плеча показывает путь к звезде) → Итоги упражнения ★★★ → «Ваш сад» (итоги сессии) → «Показать врачу» (цифры, график амплитуды по сессиям, таблица компенсаций).

## Жесты-команды (камера вместо мыши)

| Жест | Команда | Как распознаём (`src/engine/gestures.js`) |
|---|---|---|
| ✋ **Ладонь, 1 с** | ОК / дальше (кольцо заполняется) | 4 пальца выпрямлены: кончик дальше от запястья, чем средний сустав, в 1,15 раза |
| 👍 **Большой палец вверх, 0,7 с** | повторить подсказку голосом | большой палец вверх, остальные 4 пальца согнуты |
| ✋✋ **Две ладони, 0,8 с** | пауза: «Больно? Отдохните» | две открытые ладони в кадре |
| 🙋 **Поднять руку, 1 с** | выбрать руку для тренировки | запястье выше своего плеча на 0,3 ширины плеч, другая рука опущена |

Жест срабатывает **один раз за удержание**, повтор — только после того, как руку опустили. Во время упражнения работают только «пауза» и «палец вверх»: там открытая ладонь — часть движения. На паузе жесты работают, иначе паузу не снять без мыши.

## 5 упражнений

| Упражнение | Движение | Где звезда-цель |
|---|---|---|
| ★ **Звезда вверх** `reach_up` | прямая рука вперёд-вверх (сгибание плеча) | на длине вашей прямой руки (запястье + ладонь, измерено в калибровке) по направлению вашего максимума вверх |
| ★ **Звезда в сторону** `reach_side` | прямая рука в сторону (отведение, камера видит его точнее всего) | на длине прямой руки по направлению вашего максимума в сторону |
| ☕ **Чашка ко рту** `hand_to_mouth` | ладонь ко рту, как чашку чая — бытовая задача | у рта (по положению носа из калибровки), не двигается |
| ↔ **Через себя** `reach_across` | рука через грудь к противоположной стороне | за средней линией тела |
| 🖐 **Раскрыть ладонь** `open_hand` | кулак → ладонь (по 21 точке кисти) | повтор — все 4 пальца выпрямлены |

**Повтор** — машина состояний `REST → REACHING → HOLD (0,5 с у звезды) → RETURNING → REST (+1)` (`src/engine/reps.js`). Звезду «берёт» ладонь, а не запястье. Повтор засчитывается, когда рука вернулась вниз. **Пока есть компенсация, удержание у звезды не идёт**: сначала исправься — потом звезда засчитается.

**Адаптивная сложность** (`src/engine/session.js`): если человек чисто, без компенсаций, поднял руку выше звезды (больше чем на 3°, но не больше чем на 25°), звезда переезжает туда. Иначе за каждые 3 чистых повтора подряд звезда поднимается на 3°. Для «Чашки ко рту» и «Раскрыть ладонь» цель не меняется.

## Как реализован режим «ошибка»

Ошибка в Qaita — это не «не распознано», а **конкретная компенсация**: так пациент «обманывает» упражнение, и закрепляется неправильный паттерн. Сначала калибровка «Твоя норма» запоминает, как **этот** человек сидит ровно (медиана 3 секунд: ширина плеч, центр плеч, нос, расстояние ухо–плечо, ширина лица) и насколько он может поднять руку вверх и в сторону. Дальше каждый кадр сравнивается с его нормой, а не с «идеальным человеком». Все расстояния меряются в **ширинах плеч S**, поэтому неважно, далеко человек сидит или близко. Подсказка короткая, 3–5 слов: **что не так + что сделать + насколько** словами (чуть / заметно / сильно — во сколько раз превышен порог). Сантиметры человеку не показываем: камера не знает точного расстояния; оценка в см есть только в отчёте врачу. Её показывают крупно, озвучивают голосом и подсвечивают красным нужные точки на скелете.

|---|---|---|---|
| `TRUNK_LEAN_FORWARD` | лицо (внешние уголки глаз) в кадре **выросло** — человек подался к камере. Если глаз не видно — по ширине плеч. Или нос опустился | лицо > +12% (`1.12`), плечи > +15% (`1.15`), нос ниже на 0,15·S | «Чуть наклонились вперёд. / Наклонились вперёд. / Сильный наклон! Спину ровно!» |

**Бережём пациента:** два повтора подряд с сильной компенсацией (качество < 0,6) или попытка дольше 12 с → пауза «Отдохните» (событие `rest`). Повтор судим только после того, как рука хоть раз опустилась: поднятая для жеста «готов» ладонь — не ошибка.

### Надёжность: от «сырого» кадра к одной понятной подсказке

- **Сглаживание** точек: EMA, α = 0,5 (`smoothing.js`). Точки с `visibility < 0,5` не используем (`geometry.js`).
- **Проверяем с первого кадра движения**, а не только у звезды: корпус начинает компенсировать раньше руки.
- **Debounce** (`tracker.js`): ошибка показывается, если держится **≥ 300 мс**, и снимается после **≥ 500 мс** без нарушения. Одиночный «глюк» кадра подсказку не вызывает.
- **Одна подсказка за раз**, по приоритету: не та рука → корпус вперёд → корпус вбок → плечо → локоть → скорость → амплитуда → пальцы.
- **Звезда блокируется сразу** по «сырому» сигналу, не дожидаясь 300 мс: иначе быстрый повтор с компенсацией успел бы засчитаться. Не блокируют только `INCOMPLETE_ROM` и `WRONG_HAND` — они про прошлое движение или про другую руку.
- **Исправился — хвалим:** событие `mistake-cleared`, на экране «Отлично, так правильно!», в игре +50 очков. Подсказки, которые гаснут сами по таймеру (`TOO_FAST`, `INCOMPLETE_ROM`), исправлением не считаются.
- **Качество повтора** = 1 − доля кадров с нарушением. Чистый повтор — качество ≥ 0,9.
- **Человек пропал из кадра** — упражнение замирает, ошибки не «исправляются» сами.
- Голос повторяет одну и ту же подсказку **не чаще раза в 4 с** (`src/ui/voice.js`).
- **Живой голос тренера**: меню → «Живой голос тренера» — человек (с согласия) записывает 150 фраз тренера. Приложение играет запись, если она есть, а фразы без записи (например, с числами) говорит голос браузера (`src/ui/voice.js`, `src/ui/voice-lines.js`). Записи на устройстве сразу слышны в приложении; «Скачать всё» → файлы кладутся в `public/voice/`, и живой голос слышат все.

### Статусы кадра (`src/engine/framing.js`)

## Архитектура

```
        ┌──────────────────────┐   события    ┌──────────────────────┐
камера →│  src/engine/  [D]    │ ───────────→ │   src/ui/  [E]       │→ экран, голос, звук
        │  MediaPipe, норма,   │  frame, rep, │   экраны, игра,      │
        │  повторы, ошибки,    │  mistake, …  │   прогресс           │
        │  жесты               │ ←─────────── │                      │
        └──────────────────────┘  setExercise,└──────────────────────┘
                   ▲              pause, …               ▲
                   └──────── src/contract.js ────────────┘
                     (docs/CONTRACT.md — единственная граница)
```

- **Движок** (`src/engine/`) — камера и модели (`camera.js`, `models.js`), цикл кадров и сглаживание (`loop.js`, `smoothing.js`), снимок тела (`body.js`, `geometry.js`), проверка кадра (`framing.js`), калибровка (`calibration.js`), упражнения и повторы (`exercises.js`, `reps.js`), ошибки (`mistakes.js`, `tracker.js`), одно упражнение целиком (`session.js`), жесты (`gestures.js`), итоги (`summary.js`), сборка всего — `index.js`. DOM не трогает, кроме своего `<video>`.
- **Контракт** (`src/contract.js`, `docs/CONTRACT.md`) — события `frame`, `status`, `calibration`, `target`, `rep`, `mistake`, `mistake-cleared`, `gesture`, `exercise-done` и метод `getSummary()`.
- **Интерфейс** (`src/ui/`) — экраны, кольцо «ладонь», голос (`speechSynthesis` ru-RU), звуки (Web Audio), игра «Сад Qaita», история в `localStorage`. **UI не считает углы и ошибки**: тексты подсказок пишет движок, знание о теле живёт в одном месте.
- **Mock-движок** (`src/mock/`) — тот же API без камеры (`?mock=1`), чтобы интерфейс делался параллельно с движком.

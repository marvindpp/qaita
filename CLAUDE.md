## Команды
- `npm i` — поставить зависимости
- `npm run dev` — локально на http://localhost:5173 (камера работает на localhost)
- `npm run dev` + `?mock=1` — UI без камеры
- `npm test` — тесты движка
- Деплой: каждый push в `main` → GitHub Actions → GitHub Pages

## 🎮 Игровые правила (общие, утверждены 28.09)

Реабилитация скучная, и это главная причина, почему люди бросают. Поэтому упражнения — это игра **«Сад Qaita»**.

| Механика | Правило | Откуда данные |
|---|---|---|
| **Звезда-цель** | Дотянулся до ★ и держишь 0,5 с — повтор засчитан. Пока есть компенсация, звезда не засчитывается. | `target`, `rep` |
| **Очки** | Повтор = `100 × quality`. **Исправился** после подсказки = **+50** («за исправление» — хвалим за исправление, а не только за идеал). | `rep.quality`, `mistake-cleared` |
| **Комбо** | Чистые повторы подряд (`quality ≥ 0.9`): с 3-го ×2, с 5-го ×3. Повтор с ошибкой сбрасывает комбо. | `rep.quality` |
| **Звёзды упражнения** | ★ хоть один повтор · ★★ все повторы · ★★★ все повторы чистые | `exercise-done` |
| **Сад** | Каждое упражнение — грядка. Чистый повтор = 🌸 цветок, повтор с исправлением = 🌱 росток. Итог сессии — твой сад. Каждый день сад растёт, серия дней = сад пышнее. | `rep`, история в localStorage |
| **Сложность** | 3 чистых повтора подряд → звезда отодвигается на +5% (движок пришлёт новый `target`). | `target` |
| **Без таймера** | Спешка вредит (ошибка `TOO_FAST`). Время не ограничиваем. | — |
| **Ачивки** | «Первый шаг» (1-я сессия) · «Без компенсаций» (сессия без ошибок) · «3 дня подряд» | история |
| **Стоп-жест** | Две ладони = пауза: «Больно? Отдохните. Не занимайтесь через боль» | `gesture PAUSE` |

## 📌 Уточнения к контракту (для Ерса)

- `target.radius` — **доля ширины кадра**: рисуй `radius × ширина_видео`.
- `calibration.message` уже включает отсчёт («…Начинаем через 3…»): просто показывай его крупно.
- В `frame` кроме `hand` есть `hands` (массив до 2 кистей) — удобно рисовать обе.
- Движок сам не глушит повторы подсказок: это делает голос (правило 4 с выше).
- Проверить движок без UI можно так: http://localhost:5173/?debug=1&auto=1&side=right

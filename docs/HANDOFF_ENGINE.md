## Решения, принятые по живым тестам (не откатывай)
| Проблема на живом тесте | Решение |
|---|---|
| «Наклон вперёд 32 см», когда просто поднял руку | Точка плеча в MediaPipe «едет» с рукой → приближение меряем по **ширине лица (уголки глаз 3↔6)**, не плеч и не ушей (рука закрывает ухо) |
| Подсказка «Отлично», а ошибка висит | Движок показывает ошибку **всегда**; «не повторять голосом чаще 4 с» — забота UI |
| Быстрый повтор с компенсацией засчитывался за 300 мс debounce | Удержание блокируем по **сырому** сигналу ошибки, подсказку — после debounce |
| Звезда почти у локтя → тянется согнутой рукой → куча «локоть согнут» | Звезда на **длине прямой руки** (`baseline.armLen`, меряется в калибровке), адаптивность **по углу**, не по длине, шаг ≤25° |
| Непонятно, откуда и куда двигать | **Тень-тренер**: прямая полупрозрачная рука из плеча пользователя показывает путь старт→звезда→держим→опускаем (`drawGhost` в `src/engine/debug.js`) |
| Текст не читается издалека | Все подсказки 3–5 слов («Плечо к уху на 5 см. Опустите плечо!»), в debug шрифт огромный |
| «Нет спинки у стула» | Никаких «прижмите спину к спинке» |
| Одиночный скачок точки = «рывок» | `TOO_FAST` — только если быстро 3 кадра из 5 |

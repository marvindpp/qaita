## Правила
1. **Никогда не пушь в `main`.** Ветка `night5/<тема>` + PR на русском: что, зачем, как проверить, скриншоты до/после.
2. Не трогать движок (`src/engine/**`) и контракт. Только `src/ui/**`, `styles/**`, `index.html`, `README.md`, `docs/**`.
3. Перед PR: `npm ci && npm test && npm run build`, вывод — в описание PR. Тестов должно остаться 134, все зелёные.
4. **Ничего не переносится на вторую строку**: кнопки, пункты меню, плитки, чипы, подписи под кольцом. Если не влезает — короче текст или чуть меньше шрифт. Исключение — большие заголовки на вертикальном телефоне.
5. На экранах пациента шрифт не меньше 14px даже на телефоне; никаких %, °, см (кроме «Мой прогресс» и отчёта врачу).

`env(safe-area-inset-*)` Chromium не эмулирует. Для проверки выреза временно подставь `--gutter: 59px` и в PR покажи, что ничего не уходит под вырез.

**Все экраны пути:**
- `welcome` — с полем «Как вас зовут?» и без него, с загрузкой и советами;
- `prep`, `hand`, `goal`, `calibrate`, `demo`, `play` (с подсказкой-ошибкой: клавиша M), `exercise-done`, `rest`, `checkin`, `garden` (с открытыми окнами «Отправить детям» и «Записать голос»), `doctor`, `progress`, `profile`, `about`;
- меню ☰ открыто.

**Проверить и починить:**
- ничего не обрезано снизу и сбоку, нет горизонтальной прокрутки;
- ничего не перекрыто бургером, плашкой звука, бейджем «Вижу вас» (на 852×283 он закрывал лицо в камере на выборе руки);
- на 852×283 экран «Выбор руки» обрезал камеру снизу, в саду кольцо «Показать врачу» не влезало. Сделать так, чтобы влезало **без** уменьшения всего экрана ниже ~70%;
- на приветствии на низком экране кольцо с камерой и надписи крупнее, пустоты меньше;
- на игре камера — максимум по высоте, счёт и подсказка читаются;
- переносы на вторую строку (правило 4). Скрипт-детектор: для каждого видимого `button, .chip, .ring-label, .ring-sub, h1, h2, .stat span, .award b, .drawer li button` соберите `getClientRects()` текстовых узлов и сгруппируйте по нижней границе с допуском 0.8·font-size; больше одной группы — перенос;
- масштаб экрана не должен прыгать при повторном открытии (подгонка `fit()` в `app.js` уже пересчитывается после загрузки шрифта — не сломать).

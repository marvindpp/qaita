# «Сад Qaita»: как рисовать игру

> Правила игры утверждены в `docs/TASKS.md` («🎮 Игровые правила»). Здесь только **как это показать**.
> Картинки: `docs/design/garden/flower.svg` (🌸 чистый повтор) и `docs/design/garden/sprout.svg` (🌱 повтор с исправлением).
> Обе сами «вырастают» при появлении (CSS-анимация, 0,7–0,8 с). Если включено «уменьшить движение», сразу показываются готовыми.

## Что откуда берётся (по контракту)

| На экране | Событие движка | Правило |
|---|---|---|
| 🌸 цветок на грядке | `rep` с `quality ≥ 0.9` | чистый повтор |
| 🌱 росток на грядке | `rep` с `quality < 0.9` | был повтор, была подсказка, человек исправился |
| «+50 за исправление» | `mistake-cleared` | хвалим за исправление |
| Очки за повтор | `rep.quality` | `100 × quality`, комбо ×2 с 3-го чистого подряд, ×3 с 5-го |
| ★ / ★★ / ★★★ | `exercise-done` | ★ хоть один повтор · ★★ все · ★★★ все чистые |
| Грядка | одно упражнение (`exercise`) | 5 упражнений = 5 грядок |

## Грядка во время игры (экран 6)

Грядка — узкая полоса внизу экрана, **не мешает видео**. Слева направо — слоты под `targetReps` повторов.

```
┌───────────────────────────────────────────────┐
│                  (видео)                      │
│                                               │
├───────────────────────────────────────────────┤
│  🌸   🌸   🌱   ·    ·        3 из 5          │  ← грядка, высота ~96px
└───────────────────────────────────────────────┘
   ▲ выросло      ▲ пустые слоты (точка-лунка)
```

- Новый цветок «вырастает» одновременно со звуком «дзынь» и зелёной вспышкой.
- Пустой слот — маленькая лунка (`--surface-2`), чтобы было видно, сколько ещё осталось.
- Комбо ×2 / ×3 — бейдж над последним цветком, пропадает при повторе с ошибкой. Без слова «комбо»: «×2 подряд!».

## «Ваш сад» — итог сессии (экран 8)

```
┌───────────────────────────────────────────────┐
│               Ваш сад сегодня                 │  ← 48px
│                                               │
│  Звезда вверх   🌸 🌸 🌸 🌸 🌸   ★★★          │
│  В сторону      🌸 🌸 🌱 🌸 🌸   ★★           │
│  Чашка ко рту   🌸 🌱 🌸 🌸 🌸   ★★           │
│  Через себя     🌸 🌸 🌸 🌸 🌸   ★★★          │
│  Ладонь         🌸 🌸 🌸 🌱 🌸   ★★           │
│                                               │
│  🌱 = вы заметили ошибку и исправились. Это   │  ← пояснение 24px, --muted
│       тоже победа!                            │
│                                               │
│  Рука поднялась выше, чем вчера 🎉            │  ← слова, не цифры
│  3 дня подряд — сад становится пышнее          │
│                                               │
│            ✋ Ладонь — дальше  (кольцо)         │
└───────────────────────────────────────────────┘
```

- **Никаких процентов и градусов** на этом экране (урок COCARE, `docs/PLAN.md` §9). Цифры — только на экране 9 «Показать врачу».
- «Выше, чем вчера» — сравнение `bestRomDeg` с прошлой сессией из localStorage. Нет прошлой сессии → «Первый сад посажен!».
- Серия дней: 1 день — одна грядка; 3+ дня подряд — по краям появляются кусты/бабочка (декор, можно добавить позже).

## Ачивки (плашки поверх сада, по одной)

| Ачивка | Когда | Текст |
|---|---|---|
| Первый шаг | первая сессия | «Первый шаг сделан. Вы молодец!» |
| Без компенсаций | `accuracy = 1` за сессию | «Ни одной ошибки — рука работает сама» |
| 3 дня подряд | серия ≥ 3 | «Три дня подряд. Так и восстанавливаются» |

## Цвета (из `tokens.css`)

Цветок: лепестки `#F4A6B8`, серединка `--star` `#F2B233`, стебель `#2F8A57`, листья `#4FB27A`.
Росток: листья `#6CC48F` с обводкой `#2F8A57` — светлее цветка, чтобы 🌸 и 🌱 отличались и **формой**, и цветом (для дальтоников).

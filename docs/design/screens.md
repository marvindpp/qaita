# Макеты 9 экранов (словами и ASCII)

> Порядок и содержание — из `docs/TASKS.md` (раздел [E], «Экраны»). Токены — `docs/design/tokens.css`.
> Главное правило: **пожилой человек без очков понимает экран за 3 секунды**. Одна мысль на экран, одна подсказка за раз.
> Навигация без мыши: кольцо «✋ ладонь 1 сек» на каждом экране (событие `gesture` `PALM_HOLD`, `progress` 0..1 → заполнение кольца). Мышь/Enter — запасной путь, но не основной.

Обозначения: **КРУПНО** = 48–56px жирный · обычный = 26–32px · мелко = 24px (меньше не бывает).

## Общие элементы

**Кольцо «ладонь»** — всегда внизу по центру, 120px. Внутри ✋, под ним подпись «Покажите ладонь — дальше».
Заполняется по `gesture.progress`. На `fired: true` — короткая зелёная вспышка и звук. При `progress: 0` кольцо сбрасывается плавно.

```
      ╭──────╮
     │  ✋   │   ← дуга заполняется по часовой, цвет --ok
      ╰──────╯
  Покажите ладонь — дальше
```

**Плашка «Вижу вас ✓»** — в углу видео, зелёная рамка вокруг видео, когда `status.code = OK`. Когда не OK — рамка серая, вместо плашки текст статуса (`status.message`) крупно.

**Кнопка звука** — маленькая, правый верхний угол; жест «палец вверх» повторяет подсказку голосом.

## 1. Приветствие

```
┌──────────────────────────────────────────┐
│                                          │
│                 Qaita                    │  ← КРУПНО, 56px
│      Упражнения для руки дома            │  ← 32px
│                                          │
│  🔒 Видео не записывается и никуда       │  ← 26px, --muted
│     не отправляется. Всё считается        │
│     на вашем компьютере.                  │
│                                          │
│  ⚕ Не заменяет врача. Делайте только     │  ← 24px, --muted
│     упражнения, которые назначил врач.   │
│                                          │
│              ( ✋ кольцо )                │
│         Покажите ладонь — начать         │
└──────────────────────────────────────────┘
```
Крупно: название и кольцо. Мелко: дисклеймер. Видео ещё не показываем (или маленькое превью справа, чтобы человек видел, что камера включилась).

## 2. Подготовка

```
┌──────────────────────────────────────────┐
│  Подготовка                              │
├───────────────────────┬──────────────────┤
│  ✓ 🪑 Сядьте на стул  │  ┌────────────┐  │
│  ✓ 💻 Камера на уровне│  │ видео +    │  │
│       груди, ~1 метр   │  │ пунктирный │  │
│  ✗ 💡 Свет спереди     │  │ силуэт     │  │
│  ✓ 🙋 Видно голову,    │  │ (белый →   │  │
│       плечи и руки     │  │  зелёный)  │  │
│  · 👕 Одежда с рукавами│  └────────────┘  │
│  · ✋ Больно — стоп     │                  │
├───────────────────────┴──────────────────┤
│   Темновато. Включите свет или сядьте    │  ← текст статуса движка, 32px
│   лицом к окну                           │
│              ( ✋ кольцо )                │  ← активно, только когда всё ✓
└──────────────────────────────────────────┘
```
Галочки 💡 и 🙋 ставит движок (`LOW_LIGHT`, `TOO_CLOSE`/`TOO_FAR`/`LOW_VISIBILITY` → ✗). Остальные правила — просто иконки-напоминания. Силуэт — как в `?debug=1&auto=1`. На телефоне: видео сверху, список снизу.

## 3. Выбор руки

```
┌──────────────────────────────────────────┐
│   Поднимите руку, которую                │  ← КРУПНО
│   будем тренировать                      │
│  ┌────────────────────────────────────┐  │
│  │  ( ○ )        видео        ( ○ )   │  │  ← два кольца над плечами
│  │  левая                     правая  │  │    заполняются по RAISE_LEFT/RIGHT
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```
Кольца стоят **над плечами в зеркале**: левая рука человека — слева на экране. Сработало → «Тренируем правую руку ✓» на 1,5 с и голос.

## 4. Калибровка «Твоя норма»

```
┌──────────────────────────────────────────┐
│  ┌────────────────────────────────────┐  │
│  │              видео                 │  │
│  └────────────────────────────────────┘  │
│   Поднимите правую руку вверх как можно  │  ← calibration.message, 32–40px
│   выше — без боли. Начинаем через 2…     │
│   ▓▓▓▓▓▓▓▓░░░░░░░░░░░░                   │  ← progress, без цифр и %
│   ● ● ○   (фаза 2 из 3 — точками)         │
└──────────────────────────────────────────┘
```
Текст берём из движка как есть — отсчёт уже внутри. Полоска по `progress`. На `done` — «Готово! Ваша норма сохранена» + звук.

## 5. Демо перед упражнением

```
┌──────────────────────────────────────────┐
│          Звезда вверх                    │  ← КРУПНО
│                                          │
│          ┌──────────────┐                │
│          │ человечек    │                │  ← docs/design/demos/reach_up.svg
│          │ (анимация)   │                │    ~40% высоты экрана, 2 цикла = 6 с
│          └──────────────┘                │
│   Поднимите прямую руку к звезде.        │  ← 1 фраза, 32px + голос
│   Спина прижата к стулу.                 │
│              ( ✋ кольцо )                │  ← дальше только по жесту
└──────────────────────────────────────────┘
```
SVG для левой руки отражаем `transform: scaleX(-1)`. Фразы: reach_up «Поднимите прямую руку к звезде» · reach_side «Отведите руку в сторону до звезды» · hand_to_mouth «Поднесите руку ко рту, как чашку» · reach_across «Потянитесь рукой к противоположному плечу» · open_hand «Сожмите кулак, потом медленно раскройте ладонь».

## 6. Игра

```
┌──────────────────────────────────────────┐
│ Вижу вас ✓                    🔊         │
│ ┌──────────────────────────────────────┐ │
│ │               ★  (пульсирует)        │ │  ← target: x,y; radius × ширина видео
│ │             ╱                        │ │
│ │          ╱ пунктир кисть → звезда    │ │
│ │   ●────●──●  (плечи + рабочая рука)  │ │  ← упрощённый скелет, --skeleton
│ │         видео (зеркало)              │ │    точки из mistake.landmarks → красные
│ └──────────────────────────────────────┘ │
│ ┌──────────────────────────────────────┐ │
│ │ ✋ Плечо поднялось к уху — опустите   │ │  ← ОДНА подсказка, 32px, --err-soft
│ │    плечо вниз и поднимайте только руку│ │    на mistake-cleared → «Отлично, так
│ └──────────────────────────────────────┘ │    правильно!» (--ok-soft) на 2 с
│  🌸 🌸 🌱 · ·                  3 из 5    │  ← грядка + счётчик КРУПНО
└──────────────────────────────────────────┘
```
Крупно: звезда, подсказка, «3 из 5». Мелко: «Вижу вас». Зелёная вспышка рамки на `rep`. Голос озвучивает `mistake.message`, одну и ту же подсказку — не чаще раза в 4 с. На жест `PAUSE` — затемнение и «Больно? Отдохните. Не занимайтесь через боль».

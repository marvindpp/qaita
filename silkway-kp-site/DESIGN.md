# Дизайн-спек

## Настроение
Деловое, уверенное, без «маркетингового» шума. Похоже на одностраничник хорошего B2B-сервиса: крупные заголовки, короткие абзацы, чёткие карточки, одна акцентная кнопка. Клиент должен подумать «человек понимает, что делает», а не «мне что-то продают».

## Цвета
```
--bg:        #F4F1EA   фон страницы (тёплый светлый)
--ink:       #10192B   основной текст, тёмные блоки
--ink-2:     #1B2740   карточки внутри тёмных блоков
--muted:     #5B6678   вторичный текст на светлом
--muted-dk:  #9FABBD   вторичный текст на тёмном
--line:      #E6E1D6   рамки карточек
--card:      #FFFFFF   светлые карточки
--accent:    #D9451C   акцент: цена, нумерация, кнопка, метки дней
--accent-dk: #B23412   hover кнопки
```
Контраст: весь текст не ниже 4.5:1. Серый #5B6678 на #F4F1EA проходит, светлее не делать.

## Типографика
- Заголовки: `Unbounded`, 700 для H2, 900 для H1 и цены. Letter-spacing -0.01em на H1.
- Текст: `Manrope`, 400 обычный, 600 выделенный, 800 для меток и кнопки.
- Размеры (desktop / mobile):
  - H1: 80px / 40px, line-height 1.02
  - H2: 38px / 26px, line-height 1.15
  - Цена: 72px / 44px
  - Текст в карточках: 18px, line-height 1.4
  - Подзаголовки и абзацы: 18-24px, line-height 1.5
  - Метки (uppercase, letter-spacing 0.1em): 13-15px
- Используй `clamp()` для H1, H2 и цены.

## Сетка и отступы
- Контейнер: `max-width: 1120px; padding: 0 24px; margin: 0 auto`.
- Вертикальный ритм между секциями: 72-80px desktop, 48-56px mobile.
- Карточки: радиус 18-24px, padding 28px, gap между карточками 16-20px.
- Сетки карточек: `grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`, чтобы на телефоне складывались сами.

## Секции сверху вниз
1. **Шапка**: имя слева, надпись справа. Высота ~80px. Фон страницы.
2. **Hero**: тёмный блок `--ink` на всю ширину. Внутри: надзаголовок с короткой оранжевой чертой слева, H1, подзаголовок, ряд из трёх мини-карточек `--ink-2` с цифрами.
3. **Что делаю**: H2 + сетка 2×2 белых карточек с оранжевой нумерацией 01-04.
4. **Как проходит неделя**: H2 + три колонки под верхней линией 2px `--ink`. В каждой: оранжевая метка «День 1-2» и текст.
5. **Цена**: один оранжевый блок, радиус 24px. Слева надпись и цена 100 000 ₸ белым, справа два условия.
6. **Кейсы**: H2 + подзаголовок. Две карточки: белая со скрином кабинета сверху (`assets/cabinet-balcony.webp`, подпись под ним, по тапу открывается в полный размер) и тёмная с двумя скринами кабинета (`assets/cabinet-tmin-1.webp`, `assets/cabinet-tmin-2.webp`) и большой оранжевой цифрой 450%. Под ними белая плашка с оранжевой левой границей 4px (честная строка про карго).
7. **CTA**: тёмный блок, радиус 24px. Слева заголовок и строка, справа оранжевая кнопка `Написать в ватсап` (высота 56px, радиус 14px, ссылка на wa.me).
8. **Футер**: две строки серым, 15px.

## Поведение
- Кнопка ватсап: `<a href="https://wa.me/..." target="_blank" rel="noopener">`. На мобильном пусть будет ещё одна такая же кнопка сразу под ценой, чтобы не скроллить до конца.
- Лёгкое появление секций при скролле допустимо (opacity + translateY 12px, 300ms), но не обязательно. Никаких параллаксов и тяжёлых анимаций.
- `prefers-reduced-motion`: анимации выключить.

## Чего избегать
Градиенты, тени «на всё», эмодзи, стоковые иконки, картинки грузовиков и контейнеров из стоков, карусели, счётчики, таймеры обратного отсчёта, попапы.

## Проверка перед деплоем
- Открыть на ширине 390px: нет горизонтального скролла, карточки в одну колонку, H1 не вылезает.
- Все тексты совпадают с COPY.md.
- Номер в ссылке wa.me правильный.
- `<title>`: «Тест рекламы на 7 дней для Silkway Cargo».
- Добавить `<meta name="robots" content="noindex">`, это личное КП, индексировать не нужно.
